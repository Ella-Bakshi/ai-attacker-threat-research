# 19 November 2026: exact software distribution and embedded assets

We independently acquired two exact ARTEX-family software references from the [hash list published by ReversingLabs on 18 November](https://www.reversinglabs.com/blog/threat-researchers-notebook-detection-strategies-for-artex-and-related-forks). This adds eight own evidence memberships: four newly computed MD5/SHA1 values and four corroborations of existing SHA256/favicon values. These identify software, with an evidence-score ceiling of 20. There is no newly verified malicious C2 IP.

The Linux AArch64 reference is byte-identical to the `artex` member of the maintainer-published [`jiwoochris/artex-global` v0.3.15-global.1 release](https://github.com/jiwoochris/artex-global/releases/tag/v0.3.15-global.1). We independently downloaded that release archive, checked its full SHA256 against the GitHub asset digest and compared the member's exact bytes. This establishes the distributed file's identity; it does not reproduce a build from source or assess all its behavior. This fork remains distinct from the official BaaRai repository.

Both references contain the same 15,086-byte favicon already documented from pinned ARTEX source. We recovered its exact byte ranges and both Go embedded-file records naming the ordinary favicon and its Next.js static-media alias. Each pointer, length and Go toolchain content hash agrees with the recovered bytes. The ordinary SHA256 fingerprint and the Go-internal content hash are different representations; the latter uses the first 16 bytes of SHA256 over `0x01 || asset_bytes` for this asset size. See [reproducible locators](static-artifact-evidence.json). A copied favicon cannot establish a malicious operator.

Go metadata claims different versions/revisions for these references. These compiler-supplied strings are not treated as proof of exact generating source. No configured malicious endpoint or new relationship to the 35 unresolved records was recovered. Sample execution, active controller requests and scans were not performed; raw files and native projects remain private.
