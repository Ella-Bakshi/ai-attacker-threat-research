# Exact public artifacts: NIK C2 and modified Claude Code extension

Reviewed on 16 November 2026. This pass acquired two exact public historical artifact members, totaling 10,380,666 bytes, and independently checked their whole-file identities before static analysis. The [acquisition identities](acquisition-identities.json) preserve the publisher hash bridges, archive members, retrieval times, sizes and local digest calculations. The files were never executed. This is expanded-family analysis: no new exact ARTEX or CyberStrikeAI campaign sample was obtained here.

The NIK C2 PE has SHA-256 `ae38f1181c9dd0db7224d6023e335eb2cdabb0f441906d14ffba8602b7abca3c` and 6,687,744 bytes. Its identity occurs in the pinned [Talos IOC file](https://github.com/Cisco-Talos/IOCs/blob/05b70ee7773840bf7cb75150bcd5cbbe61772ddb/2026/10/nik-c2-new-ai-enabled-framework.json), associated with the [29 October original investigation](https://blog.talosintelligence.com/nik-c2-new-ai-enabled-framework/). The exact member was acquired from the public 30 October daily malware archive. Ghidra 12.1.4 reconstructed 16 selected application functions; Capstone independently checked the relevant original pointers, lengths, direct callees and argument flow. This finite scope does not cover all 261 recovered application functions or 6,571 Go/runtime functions, and reconstructed types are approximate.

The sample's native string decoder recovers `https://total-sitevv[.]lol:443` as its configured primary base. The heartbeat routine appends `/api/c2/update` and passes the resulting URL to the HTTP POST method. A separate hardcoded `https://2[.]26[.]51[.]12:443` is selected only if the assembled server list is empty. The valid primary configuration is nonempty in this exact artifact, so the fallback branch is not initially needed. No primary or fallback exchange was observed. Its literal fallback IP already has a separate source membership; these URL derivations add no new IP value.

Additional native facts concern conditional `NIKClient` Run-key naming, a single-instance mutex pattern, a temporary PID-file pattern and an embedded build source path. The 16 hexadecimal characters in the mutex/PID names derive from SHA-256 of the executable **path string**, rather than executable file contents. These host and source patterns stay software fingerprints at score 20. Their static presence does not show that persistence occurred on a victim or establish a validated detector.

The second artifact is the 3,692,922-byte modified `extension.js` whose SHA-256 is `ecb58cb29078d9646ad1dcdbe51526f2d9cfea06be5fb2ab183e8ecc3ab6bf15`, exactly matching [Cursor's incident notice](https://cursor.com/blog/claude-code-extension-security-notice). The independently inspected injected prologue occupies bytes 0–7,385, including its trailing separators before `var __EXT_BUNDLE_URL`. Its fragment hash is explicitly labeled as a fragment identity, not a whole-file malware hash. The bundled remainder was not exhaustively analyzed.

Plaintext static data flow establishes a conditional `.stk_` tunnel-key filename whose suffix is the first ten hexadecimal characters of MD5 over hostname concatenated with home, the `com.apple.sysmond` LaunchAgent label, and the already reported external POST URL. Two SSH public-key fingerprints were recomputed from the exact public blobs; private key material was excluded. The loopback sibling, public IP services, Apple DTD and normal bundled Anthropic endpoints are not classified as malicious infrastructure. Cursor reports that the attacker server was taken offline; this analysis made no request to it.

The reviewed [observations](observations.csv) contain 19 independently derived memberships: 13 type/value pairs new to the repository and six additional byte-backed memberships for existing values. Ten identity/configuration observations use score 60; nine software, fragment or host naming fingerprints use score 20. The scores express evidence strength, not maliciousness probabilities. There are zero new IP values and zero newly verified malicious C2 IPs. The AI association of the modified extension is delivery through an AI development tool; it is not proof that AI generated the payload or that a legitimate upstream extension was malicious.

The [structured evidence](exact-artifact-evidence.json) separates original publisher context, acquisition, exact native/syntax derivation, conditional behavior and unresolved runtime attribution. Article bodies, sample binaries, keys, native project files and raw decompiler output are excluded. No controller was launched, target resolved/probed, sample submitted, or paid provider called.
