# Additional analyst-derived static host/protocol patterns

Ten records were derived from the existing acquired CyberStrikeAI-lineage ELF without execution, deployment contact or Censys use. They add conditional host-forensic and decrypted-structure patterns, not new malicious infrastructure or India targeting. No campaign/operator association is established.

The useful additions are the optional cron startup entry and bashrc `# cs` nohup format, the crontab merging process pattern, temporary screenshot file `/tmp/.cs_ss.png` and its ImageMagick/base64/delete chain, generated implant UUID construction, outgoing check-in JSON schema, and file-transfer/result structures. `main.taskPersist` invokes the Linux persistence routine only upon a corresponding task; branches depend on method, permission and command success. `main.taskScreenshot` invokes its capture chain only if requested, and can fail if dependencies/display access are absent. Static code does not show a cron job, file or screenshot was actually created.

Every record has the exact sample SHA256, byte offsets/native function entries, decompilation/disassembly digests and a pinned source comparison. Source commit b43bdb... is corroborating lineage, not an assertion that it exactly generated the older sample. Recovered Go types/control flow remain approximate. UUID components and file paths are runtime data, not leaked actual host/user values. Outgoing check-in/file/result schemas are encrypted on the wire and should not be treated as plaintext network signatures.

The new compound YARA identifies the generated ELF persistence implementation; it matched the acquired sample and did not match five reference/component/tool controls. It does not mean persistence ran. The Sigma screenshot rule is experimental: YAML and five synthetic process-event controls passed; no Sigma backend conversion, sensor replay, PCAP or production false-positive test was performed. Publish it under an experimental detection folder. Neither rule independently establishes compromise or CyberStrikeAI campaign attribution.
