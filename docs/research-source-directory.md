# Research sources and collection methods

Reviewed **21 November 2026**. This directory records useful reporting, discovery collections and collection-design references from the extended hunt. It is a reading and monitoring resource, separate from the indicator catalog. A linked page can be useful without supplying an admissible IOC. Dates below are publication or update dates, not automatically attack dates. This is a finite reviewed selection, with additional source windows and unresolved candidates retained privately.

## Developing our own collection

[Our collection method](original-ioc-collection.md) distinguishes independent extraction from first-party telemetry. No owned attack sensor is deployed. Practical development proceeds through:

1. **Exact artifacts now:** source-to-hash bridge, bounded acquisition, offline static extraction, native/configuration locators, independent review and exact-value deduplication. An additional hash is an identity corroboration, not a new C2.
2. **An owned passive sensor when provisioned:** isolated hosting/domain, session-linked UTC logs, no forwarding or payload execution, restricted egress and an explicit retention/redaction policy. Inbound activity alone establishes contact with the sensor, not AI-tool identity or C2 ownership.
3. **Evidence-driven attribution:** correlate exact recovered artifacts/protocols, session behavior and source/version controls. Client-supplied names, puzzle solves and JA4/JA3 alone stay hypotheses.

[Lauren Proehl's first-party canary study](https://dispatch.thorcollective.com/p/i-leaked-credentials-on-purpose-for) (12 Nov, study 7 Jul–7 Nov) illustrates a separate measurement: unauthorized use of permissionless bait keys and fake SMTP services. Failed API calls measure attempts, and the mail sink delivered nothing. These are useful design lessons; they neither prove every key user ran ARTEX nor mean this project has deployed equivalent infrastructure. We did not create cloud credentials, seed keys, submit samples, operate a relay or run an active counter-control system during this hunt.

The method references below include newer creators and papers. Their source availability, experimental scope and false-positive limits matter more than popularity or claimed detection rates.
