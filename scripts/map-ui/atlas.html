Evidence details

Read the evidence.

This collection combines published incident indicators, independent sample/sandbox observations, passive deployment leads and unresolved context. Those categories are preserved in every view; an address on the map is not a verdict.

  • Scores summarize a documented evidence rubric. They are not probabilities of maliciousness.
  • India C2 uses india_campaign_c2_supported from the same source record. Other membership filters can combine separate observations for one IP.
  • IP geolocation estimates hosting geography. It does not identify a victim, operator, hosting customer or attack-time location.
  • Coordinates come from the stated provider snapshot. Addresses without coordinates remain in the inventory and CSV.
  • Markers cluster nearby coordinates. Co-located addresses can be inspected in the complete paged member list.

IP Geolocation by DB-IP, CC BY 4.0. Boundaries use the reviewed Natural Earth India point of view, via the pinned geojson-regions dataset. It depicts countries and territories; it is not a government-certified map.
