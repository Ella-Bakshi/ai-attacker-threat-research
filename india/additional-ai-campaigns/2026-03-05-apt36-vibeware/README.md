# APT36-vibeware: India targeting evidence

Publisher: **Bitdefender**. Publication date: **2026-03-05**. Reviewed: **2026-11-10**.

The primary report links this campaign to Indian government or diplomatic targets and assesses AI-assisted malware development. This is a separate campaign; no ARTEX, CyberStrikeAI or CRAFTY FALCON relationship has been established. India is a campaign-level targeting association, not a claim that each value identifies an exclusively Indian victim or a current compromise. Bitdefender assesses the APT36 attribution with medium confidence. Five collateral hashes explicitly described as NOT indicative of APT36 remain supporting context.

This folder contains **50 source-reported IOC records**, **8 additional report artifacts**, and **5 supporting/context records**. Three hashes of one file count as three indicator values, not three malware samples. Host artifacts require correlation. Legitimate provider, DNS, CDN and certificate infrastructure is not a block list.
