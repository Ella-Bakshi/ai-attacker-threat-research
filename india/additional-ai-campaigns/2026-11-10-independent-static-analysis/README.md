# Independently inspected APT36 vendor-listed helper

This supplementary campaign evidence is separate from ARTEX and CyberStrikeAI. Bitdefender's **5 March 2026** report associates APT36/Transparent Tribe with Indian government and diplomatic targeting and assesses AI-assisted malware development in the broader campaign. Neither country targeting nor AI authorship is independently demonstrated by this one helper. No ARTEX/CyberStrikeAI link was established. [Primary report](https://www.bitdefender.com/en-us/blog/businessinsights/apt36-nightmare-vibeware) · [Pinned vendor IOC row](https://github.com/bitdefender/malware-ioc/blob/5a4f9b09091d530ab99dabad044bd542c2bd5e12/2026_03_05-apt36-iocs.csv#L43).

We acquired the exact `filecopyU` artifact listed by the vendor under MD5 `3e9b3306644b1a4d8c3ac23c7e0d4c7b` from a public MalwareBazaar archive. Local SHA-256 is `41dfa4fbcc8c68d98a2e773bb2de3df0b136ee9b608351290738d953ccbcc309` and SHA-1 is `795981d6a13880fecb05adaa8503e72c9524ba11`. Size: **70,424 bytes**. These cross-hashes also appear in a [public Triage General table](https://tria.ge/260728-n7esxswanf); they are independently verified here, not globally novel discoveries. The archive date, **28 July 2026**, is an archive membership date, not a demonstrated first deployment or attack date. Acquisition and review: **10 November 2026 UTC**.

The artifact contains two complete managed methods. `FileCopy.Program.Main`, token `0x06000001`, RVA `0x2050`, has a tiny method header at decimal file offset **592** and **12 bytes** of CIL at **593**. It loads user string `0x70000001`, calls MemberRef `0x0a00000f`, discards the return value and returns. Independent token resolution identifies `System.IO.Directory.CreateDirectory`; the UTF-16LE argument **`C:\Users\Public\Documents\Temp`** occupies **60 bytes at file offset 1810**. Both methods were fully decoded and cross-checked against the REA static managed provider. We found no file-copy or network operation in those admitted method bodies. The vendor component name `filecopyU` alone is insufficient evidence of richer behavior.

The host directory has **low detection specificity**. It is a conditional path requested by static code, with no observed folder creation or execution. Do not use its existence alone to declare compromise, assign APT36 or identify Indian targeting. The module MVID and method IL hash are separate **software fingerprints**; the 12-byte tokenized method body is too small to claim uniqueness and must be interpreted with its module and sample hash. **No new C2 endpoint was recovered.**

The five publication records comprise two verified file cross-hashes, one conditional host-directory artifact and two software fingerprints. The CSV MD5 remains the vendor's original observation. Our contribution is exact-byte verification, managed-token resolution and clearly scoped host/identity evidence. No global-novelty claim is made.

Acquisition search was bounded: 42 exact vendor seed hashes were searched in public Triage; six yielded public cross-hash metadata. Nine public MalwareBazaar daily archive directories totaling **4,260 entries** produced this one exact sample. Five other MD5 lookups in CIRCL returned 404. This does not establish that other samples are unavailable elsewhere.
