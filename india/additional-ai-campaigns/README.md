# Additional AI-assisted campaigns targeting India

These campaigns expand **AI Attacker Threat Research** beyond ARTEX/CyberStrikeAI. Primary vendors describe Indian government or diplomatic targeting and assess AI-assisted malware development. No link to ARTEX, CyberStrikeAI or CRAFTY FALCON is established. Attribution and AI assessments remain attributed to their publishers.

There are **171 externally sourced IOC records**, **32 additional report artifacts**, **6 supporting/context records**, and **5 independently verified/derived observations**. A hash algorithm is an indicator type: three hashes of one file are three values, not three samples. Neither a country-code domain nor an IP hosting country proves targeting.

India targeting is supported at campaign scope. Every record separately states whether a particular Indian victim's compromise is confirmed; none is inferred. The exact restricted CERT-In CRAFTY FALCON IOC set remains unavailable. Tenant/resource URLs are narrower than shared cloud provider domains. Certificate validation URLs and ordinary DNS resolvers are excluded from malicious network IOC claims. Dates are publication/review dates; blank first/last-seen values mean unknown.
